Django: O framework base.

djangorestframework: Essencial para criação da API REST.

mysqlclient: O driver mais rápido e recomendado pela documentação do Django para conectar ao MySQL.

django-cors-headers: Necessário para permitir que o seu front-end consuma a API do Django sem bloqueios de segurança do navegador.

python-dotenv: Para gerenciar variáveis de ambiente , tirando o hardcode do settings.py.

drf-spectacular: O padrão atual no ecossistema DRF para geração automática de documentação OpenAPI/Swagger.

instalação:
pip install django djangorestframework mysqlclient django-cors-headers python-dotenv drf-spectacular
